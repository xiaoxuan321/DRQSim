Five-module What-if Parameter Editor
What-if modules: parameters are grouped according to the active DRQSim simulation logic: control-flow decision points, case arrival workload, dynamic resources, queue scheduling, and service / external delay.
Module 1 · Control Flow
Edit decision-point branch probabilities and safe decision-tree rules. Trace attributes are shown here because they can drive control-flow decisions.
Trace Attributes
auxiliary context
Module 2 · Case Arrival
Adjust arrival workload, inter-case spacing, and arrival calendars. These controls mainly affect CAR, CTD, queue length, and overall congestion.
Module 3 · Dynamic Resource
Edit resource capacity, activity-resource assignments, calendars, multi-tasking capability, and DBN-based dynamic resource states.
Resources
Activity Assignments
Resource Calendars
Module 4 · Queue Scheduling
Edit queue-aware resource selection strategy, score-mixing weights, queue-state caps, and fallback behavior.
Module 5 · Service / External Delay
Edit base service-time distributions and residual external-delay controls. Queue waiting is generated by queue scheduling; external delay represents non-resource waiting.
